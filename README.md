# Nature Website
A visually engaging and fully responsive website themed around nature and the environment.This project aims to showcase a clean and calming design using 
HTML, CSS, and JavaScript, suitable for a nature blog, environmental NGO, or eco-awareness campaign.

## 🌐 Live Demo
(https://devadharshinipachiappan.github.io/NatureWebsite/)

## Features
 Nature-themed aesthetic with calming visuals and colors
 Responsive layout for all screen sizes
 Smooth animations and transitions
 Organized CSS architecture with reusable components
 Environmentally-conscious message delivery

# Tech Stack
 HTML5
 CSS3 (Flexbox/Grid)
 JavaScript (Vanilla)
 AOS (Animate On Scroll)
